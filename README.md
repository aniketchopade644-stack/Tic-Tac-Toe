# 🎮 Tic Tac Toe

A simple Tic Tac Toe game where a player plays against the computer.

## 🚀 Features
- Player (X) vs Computer (O)
- Smart/Random AI
- Win & Draw detection
- Reset option

## 🛠️ Tech Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run
- Open `index.html` in browser
